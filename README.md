# Junchuang E-Commerce Website

Corporate website for Junchuang E-Commerce — e-commerce retail and Google Ads API-powered digital marketing.

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About Us |
| `/services` | Services |
| `/ad-tech` | Advertising Technology |
| `/privacy` | Privacy Policy |
| `/terms` | Terms of Service |
| `/contact` | Contact Us |

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before Deployment

- [ ] Register a domain and enable HTTPS
- [ ] Update email in `src/lib/company.ts` if needed
- [ ] Deploy to Vercel or your preferred platform

## Company Info

Public-facing content is maintained in `src/lib/company.ts` (English only).
